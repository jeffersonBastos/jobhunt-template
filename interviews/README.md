# interviews/

- `feedback-log.md` — a running log of post-interview retros: what went
  well, what didn't, what you'd change next time. Keep it short and honest;
  it's for you, not for showing anyone.
- `prep/<company>/` — one folder per active interview process, for
  company-specific prep (their stack, likely rounds, questions you've been
  told to expect, notes from recruiter calls). Delete a company's folder once
  the process ends, win or lose — this is working material, not an archive.

Cross-company, reusable interview prep (algorithms, system design, general
technique) belongs in `study/` instead, so it survives past any one process.
