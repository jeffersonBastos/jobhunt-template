# references/

Save posts you want to learn from here — one file per post, named
`YYYY-MM-topic.md`. For each one, don't just copy the text: write a short
structural breakdown of *why it works* (hook, pacing, what makes the close
land) so future-you can reuse the pattern without needing the original post
in front of you.

If you quote or link to someone else's post, keep it short (a line or two,
not a full copy) and always credit the author.
